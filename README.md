# CricUmp — Umpire Scheduling (Demo)

A no-backend, single-page demo for scheduling cricket umpires in US local/youth
leagues (Seattle beachhead). Built to gather feedback on the concept and feature
set before any real build.

**Live demo:** see the GitHub Pages URL in this repo's About section.

## What it shows
- Two roles (switch top-right): **League Organizer** and **Umpire**
- Organizer: post a match, see status, confirm umpires
- Umpire: browse open matches, accept/withdraw, set weekly availability
- Umpire directory with USA Cricket certification level as a trust signal
- Notifications feed (what would be email/SMS in the real app)

## Status
Demo only. No backend, no payments, no real accounts. Sample data is stored in
your browser (localStorage); click **Reset demo data** on the Notifications tab
to restore defaults.
